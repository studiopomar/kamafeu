# OpenUtau G2P data

The `*.dict` and `*.phones` files in this directory are derived from the
language G2P packs shipped by [OpenUtau](https://github.com/stakira/OpenUtau).
They are used by Kamafeu's Rust phonemizer ports for English, French, German,
Russian, Spanish and Portuguese.

These files are data resources; the Rust runtime that reads them is Kamafeu
code.
