# Plugin phonemizer attribution

## Arabic

The Arabic rules and mapping are ported from
[dorayakito/OpenUtau.Plugin.Arabic](https://github.com/dorayakito/OpenUtau.Plugin.Arabic).
The upstream plugin is released under the MIT License.

## Icelandic

The Icelandic rules and mapping are ported from
[dorayakito/Icelandic-Diffsinger-Phonemizer](https://github.com/dorayakito/Icelandic-Diffsinger-Phonemizer).
The upstream code is released under the MIT License. The Icelandic
pronunciation dictionary data remains under CC BY 4.0, as stated by the
upstream project.
