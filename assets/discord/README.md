# Assets do Discord Rich Presence

Envie estes arquivos em **Discord Developer Portal → Applications → Kamafeu Studio → Rich Presence → Art Assets**. O portal converte as chaves em minúsculas; mantenha exatamente estes nomes:

| Arquivo | Chave | Uso |
| --- | --- | --- |
| `kamafeu_logo.png` | `kamafeu_logo` | Imagem principal do Kamafeu Studio |
| `status_edit.png` | `status_edit` | Indicador de edição |
| `status_play.png` | `status_play` | Indicador de reprodução |
| `status_render.png` | `status_render` | Indicador de exportação WAV |

Use também `kamafeu_logo.png` como ícone da aplicação em **General Information → App Icon**. Sem esses uploads, o Discord mostra `?` para as chaves que o aplicativo envia.

Todos os arquivos têm 1024 × 1024 pixels, o tamanho recomendado pelo Discord para Art Assets.
