# Notices

This repository contains an independent, reusable Rust extraction of the
Galapagos wavtool algorithms developed in Kamafeu Studio. It is distributed
under the MIT License in `LICENSE`.

The envelope and overlap-alignment concepts target UTAU-compatible synthesis
workflows. Galapagos is not affiliated with or endorsed by UTAU, OpenUtau, or
nmasao. Its automatic overlap search is inspired by public descriptions of
wavtool4vcv behavior; this repository does not contain wavtool4vcv code.
